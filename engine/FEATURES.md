# NodePilot Engine 全景功能清单 (FEATURES)

> 本文档为 NodePilot 核心网络引擎（`engine/`）的静态功能蓝图与全景能力矩阵，记录面向底层集成与 CLI 的核心架构能力。

---

## 一、 核心引擎能力矩阵 (Engine Capabilities Matrix)

| 核心组件 | 能力项 | 状态 | 技术规格说明 |
| :--- | :--- | :---: | :--- |
| **订阅与协议解析器 (`parser`)** | 多主流网络协议支持 | ✅ | 支持 Shadowsocks、ShadowsocksR、VMess、VLESS、Trojan、Hysteria2 等协议节点 URI 解析 |
| | 多元格式自动嗅探 | ✅ | 自动识别 Base64 编码、SIP002 格式、Clash YAML 配置及自定义订阅流 |
| | 容错与防御性清洗 | ✅ | 智能过滤乱码、畸形字段与冗余参数，保留标准规范化节点模型 |
| **探测与基准测试驱动 (`runner` & `probe`)** | 阶梯式链路探测栈 | ✅ | 支持 TCP 三次握手时延、TLS 协商时延、HTTP/HTTPS 首包时延（TTFB）多层探测 |
| | 高性能 Worker 池 | ✅ | 基于 Go goroutine 并发协程池架构，支持弹性 Worker 限制与平滑背压 |
| | 上下文可控生命周期 | ✅ | 深度接入 `context.Context`，毫秒级响应超时截断与外部取消信号 |
| | AI 服务专项专线探针 | ✅ | 专线探测 OpenAI (`/v1/models`)、Anthropic、Gemini、DeepSeek 等大模型端点联通度 |
| **度量与智能评分模型 (`scorer`)** | 综合健康度打分算法 | ✅ | 基于动态时延、丢包率加权、抖动方差与连通状态多因子综合评分 |
| | 评级分段与状态判定 | ✅ | 输出 A/B/C/D 梯队评级与 AVAILABLE / DEGRADED / UNAVAILABLE 强类型枚举状态 |
| **持久化与嵌入式存储 (`storage`)** | 嵌入式 SQLite 引擎 | ✅ | 零 CGO 纯 Go 驱动，保障历史测速记录、节点元数据、系统配置的高吞吐事务读写 |
| | 架构分层仓储契约 | ✅ | 纯抽象接口设计 (`Storage`)，支持无缝切换内存测试仓储与持久化生产仓储 |
| **格式转换与导出引擎 (`exporter`)** | 多客户端配置转换 | ✅ | 支持将选优节点导出为 Clash 配置、Sing-Box 出站规则及标准 JSON 集合 |
| | 批量结构化数据导出 | ✅ | 支持 CSV / JSON 格式的全量测速历史记录与诊断明细导出 |
| **领域模型与不可篡改保障 (`model`)** | 黄金断言契约测试 | ✅ | 核心领域模型配备不可篡改 Golden Tests，保障跨版本序列化与协议字段严格兼容 |

## 二、 核心管道流转拓扑

```text
               ┌──────────────────────┐
               │ 原始订阅源 / 节点 URI │
               └──────────┬───────────┘
                          │
                          ▼
               ┌──────────────────────┐
               │  Parser 协议解析适配  │
               └──────────┬───────────┘
                          │ 规范化 Node 模型
                          ▼
               ┌──────────────────────┐
               │  Runner 并发调度执行  │ ◄── ProbeProfile 配置 (TCP/TLS/HTTP/AI)
               └──────────┬───────────┘
                          │ 原始网络遥测数据
                          ▼
               ┌──────────────────────┐
               │ Scorer 算法评分加权  │
               └──────────┬───────────┘
                          │ 综合得分与可用性评级
                          ▼
               ┌──────────────────────┐
               │ Storage 持久化 / 导出 │ ──► [SQLite 数据库] / [Clash & Sing-Box]
               └──────────────────────┘
```
