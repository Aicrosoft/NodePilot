## 🎯 测试固化与防漂移基线索引 (Anti-Drift Baselines)

为防止后续在代码重构、多端适配或功能扩展过程中出现功能和特性的悄然漂移（Feature Drift），以下核心特性已明确其严格验收边界：

1. **不可绕过的可用性状态机边界**：
   - 必须保留 HTTP 401/403 映射为 `Authentication Required`，且依然视为网络可用并参与网络层指标评分；
   - 严禁将 401 误报为 `Unavailable` 或 `Timeout`。
2. **防虚假高分的一票否决与空指标防御**：
   - 评测失败或无真实响应的节点，各项性能度量（TTFB、TTFT、TPS）必须保持 0，加权综合评分必须为 0，严禁通过 Min-Max 归一化倒数反转获得高分。
3. **中转缓冲降权逻辑锁定**：
   - 当探测到节点存在明显聚合缓冲行为时（Token > 5, TTFT > 800ms, 平均间隔 < 3ms），必须强制执行 30% 综合得分削减并标记 `BufferingDetected = true`。
4. **原始节点与过滤状态双层隔离**：
   - 正则过滤操作必须保持非破坏性：仅更新当前激活视角的生效节点集合，绝对禁止物理删除数据库中存储的原始全量节点（`rawNodes`）。
5. **UI 三元交互分流红线**：
   - 高信息密度、多字段表单与复杂列表（节点详情、规则库、运行日志）必须使用右侧滑出抽屉（Drawer）；
   - 仅简短操作确认（删除确认、清空确认）使用居中紧凑对话框（Modal）；纯系统通知必须使用轻量浮动条（Toast）。
6. **图表批次离散对齐保障**：
   - 历史趋势图表必须在时间轴上采用 120 秒滑窗聚类算法实现批次对齐，严禁将同一轮测速的多节点离散点错位分散在时间轴上。
7. **CLI 零参数开箱体验与退出状态码契约**：
   - CLI 引擎零参数调用时绝不报错退出，必须自动注入 `Local-Direct` 直连探针作为开箱基线；
   - 遇到无效配置源时必须返回 Exit Code 1，正常完成必须返回 Exit Code 0，以保障 Shell/CI 脚本自动化调用。
8. **开源交付双重安全隔离红线**：
   - GitHub 开源发布流水线必须彻底排除内部思考日志（`logs/`）与私有草稿文档（`docs/` 下除 `features/` 外一律清除）；
   - 历史零碎 Commit 必须严格压缩为单个干净的 Release Commit，且必须经由服务端无代理人工放行门禁 (`ManualValidation@0`) 审核确认。
9. **凭据安全与日志运行时热切换红线**：
   - AI 服务探针 API Key 必须仅持久化于本地 SQLite 与本地缓存，绝对禁止上云或在日志中打印敏感鉴权 Header；
   - 日志级别切换必须具备防抖比对机制，相同级别不触发重置，且日志文件必须按日轮转并支持原生目录呼出与应用内高亮观测。

各特性的具体技术实现细节、数据结构与单元测试断言，请参阅上述对应规约文档。
