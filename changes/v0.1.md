# Version 0.1

### Added
- **全局关键状态全量 SQLite 数据库持久化与零感冷启动自动迁移 (物理级数据安全 + 跨会话零丢失 + 彻底解耦 Webview 缓存)**：将 NodePilot 的全部核心业务状态（包括机场列表及节点数据、订阅源、过滤规则库、最新控制台测速快照与全局偏好配置）全面从脆弱易丢失的浏览器 `localStorage` 迁移持久化至本地嵌入式 SQLite 数据库（`~/.nodepilot/nodepilot.db`）；扩展表结构实现 `app_settings`（键值对偏好）、`airports`（机场完整对象）、`rule_library`（过滤规则库）、`benchmark_latest`（最新测速快照）；所有读写受 ACID 事务与 WAL 模式保护；Wails 后端封装完备的 IPC 桥接；前端状态层引入零感知冷启动装配函数（`initSQLiteStorage`），自动嗅探并一次性将历史数据无缝导入 SQLite，彻底根除系统清理工具或 Webview 容器重置误杀配置的隐患；

- **指标维度优劣导向清晰标注 (消除判读歧义)**：在指标下拉菜单、图表顶部坐标轴单位、图例及悬浮 Tooltips 气泡中，全面标注「越高越好（↑）」与「越低越好（↓）」，中英文双语字典深度对齐（如 `🏆 Score (0~100 · Higher is better)`、`⚡ Ping (ms · Lower is better)`）；

- **轻量原生多语言国际化引擎 (默认跟随系统 + 英文 Fallback + 全界面即时无缝切换)**：新增前端纯轻量原生国际化引擎（[i18n.js](../app/frontend/src/js/i18n/i18n.js)），提供点分多级键访问、参数动态插值（`{variable}`）与 DOM 声明式翻译（`[data-i18n]`、`[data-i18n-title]`、`[data-i18n-placeholder]`）；默认选项为“跟随系统”，精准嗅探系统语言环境（非中文一律默认回退至英文）；集成 Wails 原生窗口标题动态同步（`WindowSetTitle`）；左侧主导航项精炼对齐为「节点测速 / Benchmark」、「订阅管理 / Subscriptions」、「评测历史 / History」、「偏好设置 / Settings」；英文词典全面精简瘦身（Refine & Compact），消除冗长长句，与紧凑现代开发工具 UI 风格完全契合；侧栏底部提供紧凑的三态分段控制器（`自动` / `中` / `EN`），并与偏好设置首行语言选择器双向同步联动；切换语言无需刷新页面即可实时平滑重绘，保障长耗时测速不中断；
- **桌面端三平台手动发布 CI 流水线**：重构并规范重命名为 [.azure-pipelines/ci/desktop-ci.yml](../.azure-pipelines/ci/desktop-ci.yml)，显式配置 `trigger: none` 与 `pr: none` 彻底关闭自动触发改为纯手动调度，支持多平台选择参数（`all`、`macos_and_windows`、`linux`），多 Job 并行完成 macOS Universal（`.app` / `.zip`）、Windows 64位（`.exe`）、Linux 原生桌面端（GTK3/WebKit）与 CLI 静态引擎矩阵的编译归档与 Drop 发布；
- **前置 Ping 探测与 Fail-Fast 短路熔断机制**：底层引入轻量级握手时延探测（TCP 三次握手 RTT / QUIC 握手探测），不通节点秒级快速熔断并标记离线，跳过后续耗时数秒的 AI 探针；
- **排行榜与抽屉新增「节点 Ping」列**：在节点名称与可用性之间直观展示 `⚡ 45ms`、`⚡ 160ms`、`❌ 离线`，并提供顶栏 `⚡ 前置 Ping` 实时切换开关；
- **一键导出所有机场与节点配置**：支持将所有机场名称、正反向正则过滤规则、原始及过滤后节点列表、订阅源一键序列化并导出为标准 JSON 备份文件；
- **一键导入与智能合并**：支持从备份 JSON 一键恢复，具备同名覆盖更新、新机场无缝追加、自动规则过滤与测速状态激活能力，支持系统原生保存/打开对话框与纯前端双通道；
- **AIDF 运行期日志系统与故障诊断气泡**：新增运行日志抽屉与底层追踪器，主界面鼠标悬停 `Unavailable` 胶囊可直接查看底层真实报错信息；
- **跨平台统一一键构建脚本**：根目录新增 [build.sh](../build.sh)，提供交互式终端菜单与命令行直接调用，一键编译 macOS、Windows、Linux 桌面端与三大平台 CLI 核心引擎；
- **桌面专属 Release 归档规范**：建立标准的 `release/` 目录组织结构（`release/macos/`、`release/windows/`、`release/linux/`、`release/cli/`），产物互不覆盖；
- **全协议出站代理隧道内核**：引入 `github.com/metacubex/mihomo` 原生出站解析器，在内存中直接动态实例化各协议的出站 Proxy，全面打通并真实通过节点代理访问外网，原生支持 Shadowsocks, VMess, VLESS (Reality), Trojan, Hysteria2, TUIC 等全部加密协议；
- **Windows 全尺寸多分辨率规范图标**：基于 [docs/assets/logo.png](../docs/assets/logo.png) 原图重新封装生成包含 256x256、128x128、64x64、48x48、32x32、24x24、16x16 全套 32 位真彩色无损 PNG 流的 [icon.ico](../app/build/windows/icon.ico)，彻底解决 Windows 下小图标留白、四周镂空的问题；
- **独立规则库抽屉与管理面板**：新增侧滑抽屉式的规则库管理面板，支持一键套用常用过滤策略、增删改自定义规则并持久化；
- **节点指标详情气泡提示**：在评测列表各项指标头部增加清晰直观的浮动提示卡片，明确标出指标定义、权重占比与优劣导向（越高越好 / 越低越好）。
