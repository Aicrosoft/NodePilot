# NodePilot Desktop App 全景功能清单 (FEATURES)

> 本文档为 NodePilot 桌面图形客户端（`app/`）的静态功能蓝图与全景能力矩阵，记录面向终端用户的完整产品能力。

---

## 一、 核心功能全景图 (Feature Matrix)

| 功能模块 | 能力项 | 状态 | 说明 |
| :--- | :--- | :---: | :--- |
| **桌面运行时与窗口** | 跨平台原生窗口 | ✅ | 基于 Wails v2 构建，支持 macOS (Universal/Apple Silicon/Intel)、Windows (x64/x86)、Linux |
| | 系统托盘常驻与菜单 | ✅ | 托盘图标状态响应、快捷显示/隐藏主窗口、一键退出 |
| | 窗口状态记忆 | ✅ | 自动记住上次退出时的窗口位置、尺寸与最大化状态 |
| **节点管理与视图** | 多源订阅导入 | ✅ | 支持导入多订阅链接、剪贴板一键批量解析导入、本地文件导入 |
| | 节点列表与多维检索 | ✅ | 按名称、地区、协议、可用性状态进行瞬时模糊搜索与分类过滤 |
| | 节点详情与协议透视 | ✅ | 查看节点传输协议、加密方式、混淆参数及历史测速指标 |
| **智能基准测试控制台** | 批量并发测速 | ✅ | 支持自定义并发 Worker 数与超时阈值，一键发起全量或选中节点测速 |
| | 阶段式进度与状态回传 | ✅ | 实时展示测速总体进度百分比、当前测试节点、平均延迟与完成数 |
| | 测速取消与安全中断 | ✅ | 支持在长任务测速进行中随时平滑中断，保护系统资源 |
| **数据可视化与分析** | 实时指标图表看板 | ✅ | 延迟、丢包率、首包时间（TTFB）多维指标卡片直观呈现 |
| | 双 Y 轴历史演进趋势图 | ✅ | 节点时延与丢包率联动曲线，支持自定义时间范围回放 |
| | 综合可用性评分体系 | ✅ | 结合时延、成功率与抖动自动给出节点健康评级（A/B/C/D） |
| **AI 专线探针配置** | 专线模型可用性探测 | ✅ | 支持配置 OpenAI、Claude、Gemini、DeepSeek 等 AI 接口专线连通度 |
| | 凭据本地安全存储 | ✅ | API Key 与自定义模型端点仅持久化存储于本地轻量配置库 |
| **个性化与多语言** | 深色 / 浅色主题自适应 | ✅ | 支持明亮模式、暗黑模式及跟随操作系统原生外观自动切换 |
| | 中英双语国际化 (i18n) | ✅ | 支持简体中文、英文即时无刷新界面语言切换 |
| **数据备份与迁移** | 配置全量导出与恢复 | ✅ | 支持将节点列表、订阅源与偏好设置一键导出/导入备份 |

## 二、 交互流转架构

```text
[系统托盘 / 原生窗口]
         │
         ▼
[Wails Webview 前端 (Vanilla ESM + CSS Variables)]
   ├── 节点视图 (Node List & Filter)
   ├── 测速看板 (Benchmark Dashboard & Live Chart)
   └── 系统偏好 (Settings & API Credentials)
         │  Wails Go-JS Binding 双向通信
         ▼
[Go 后端调度层 (app/app.go)]
   ├── 本地存储仓储 (Storage Provider)
   └── 核心测速驱动 (Core Engine Interface)
```
